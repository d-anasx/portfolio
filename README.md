# Anas Djamaoui — Portfolio

Personal portfolio of Anas Djamaoui, full stack & AI developer (YouCode | UM6P).

A single static page (`index.html`): a live particle field that re-forms for each project, liquid-glass UI, Web Audio sound effects, smooth scrolling (Lenis) and an EN/FR switch. No build step — Vercel serves it as is.

Projects featured: [NeuroVision AI](https://github.com/d-anasx/NeuroVision), [CrediSegment](https://github.com/d-anasx/segmentation_clients), [MoodTrace](https://github.com/d-anasx/Mood_Tracker).
